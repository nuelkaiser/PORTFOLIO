# Majekodunmi Immanuel — Portfolio

Editorial single-page portfolio inspired by [annaparellada.com](https://www.annaparellada.com/). Built with Next.js, Tailwind CSS, and Framer Motion.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- [Impeccable](https://impeccable.style/) design context (`PRODUCT.md`, `DESIGN.md`)

## Develop

From this `kaiser` folder:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Push to GitHub and import the repo in [Vercel](https://vercel.com). Set the project **Root Directory** to `kaiser`.

## Content

Update copy, projects, and contact in [`lib/content.ts`](lib/content.ts). Replace hover previews in [`public/work/`](public/work/).
