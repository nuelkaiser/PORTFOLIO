## Design Context

**Surface:** Brand portfolio (single-page editorial)

**Product:** Personal site for Majekodunmi Immanuel — Software Engineer, Lagos.

**Aesthetic:** Cool paper neutrals, Instrument Serif + Manrope, typography-led Parellada-inspired layout. Sparse nav, oversized brand name, hairline work/history rows, hover media planes. Soft atmospheric gradients + grain — not flat white, not purple, not dark neon, not cream+terracotta.

**Motion:** Scroll progress, hero type reveal, work hover preview, section enters. Expo-out easing.
